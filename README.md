# Катя и Витя в лесу

Браузерная обучающая игра для детей 2–5 лет: восемь уровней о безопасности, лесных животных, росте дерева, счёте, памяти, выборе лесных обитателей и сортировке мусора. Интерфейс и озвучка доступны на русском и казахском языках. Все задания работают с мышью и касанием.

Шестой, седьмой и восьмой уровни проходят прямо в лесном пейзаже с Катей слева и Витей справа. В каждом по три этапа с разными фонами. В игре про животных все 16 зверей и птиц показаны отдельными изображениями без подписей. В седьмом уровне ребёнок нажимает на мусор, и тот сам перемещается в нужный контейнер. В восьмом ребёнок перетаскивает мусор самостоятельно; также доступно управление «нажать предмет → нажать контейнер». На мелководье ракушки нужно оставить в природе.

## Запуск

- Откройте `dist/index.html` в браузере; или
- запустите `python launcher.py` и нажмите **«Открыть игру в браузере»**.

Windows-запускатор позволяет сохранить API-ключ локально и проверить или обновить аудио. Готовый `ForestGameLauncher.exe`, если он собран, кладётся рядом с папками `dist` и `locales`.
Готовый комплект для Windows доступен в [последнем выпуске](https://github.com/ussenko2022/katya-vitya-forest-game/releases/latest): распакуйте архив целиком и откройте `ForestGameLauncher.exe`.

Для самостоятельной сборки EXE на Windows установите PyInstaller (`python -m pip install pyinstaller`) и запустите `powershell -ExecutionPolicy Bypass -File tools/build_launcher.ps1`. Запускатор читает ключ из корневого `.env` и сохраняет изменения в тот же файл.

## Озвучка

Игра предлагает три варианта: браузерный робот, женский и мужской голос. Женский и мужской голоса созданы ИИ OpenAI. Если в браузере нет голоса для выбранного языка, игра показывает предупреждение. Предзаписанные голоса работают без обращения к API во время игры.

Для обновления фраз создайте `.env` по образцу `.env.example`, затем выполните:

```powershell
python tools/generate_audio.py --check
python tools/generate_audio.py
python tools/build_public_site.py
```

Генератор использует `gpt-4o-mini-tts` и пропускает клипы, у которых не изменились текст, язык, модель, голос и инструкции. API-ключ хранится только в локальном `.env`; в сайт он не встраивается.
