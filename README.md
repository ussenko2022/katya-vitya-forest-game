# Катя и Витя в лесу

Браузерная обучающая игра для детей 2–5 лет: пять уровней о безопасности, лесных животных, росте дерева, счёте и памяти. Интерфейс и озвучка доступны на русском и казахском языках.

## Запуск

- Откройте `dist/index.html` в браузере; или
- запустите `python launcher.py` и нажмите **«Открыть игру в браузере»**.

Windows-запускатор позволяет сохранить API-ключ локально и проверить или обновить аудио. Готовый `ForestGameLauncher.exe`, если он собран, кладётся рядом с папками `dist` и `locales`.

## Озвучка

Игра предлагает три варианта: браузерный робот, женский и мужской голос. Женский и мужской голоса созданы ИИ OpenAI. Если в браузере нет голоса для выбранного языка, игра показывает предупреждение. Предзаписанные голоса работают без обращения к API во время игры.

Для обновления фраз создайте `.env` по образцу `.env.example`, затем выполните:

```powershell
python tools/generate_audio.py --check
python tools/generate_audio.py
python tools/build_public_site.py
```

Генератор использует `gpt-4o-mini-tts` и пропускает клипы, у которых не изменились текст, язык, модель, голос и инструкции. API-ключ хранится только в локальном `.env`; в сайт он не встраивается.

## Публикация

Папка `docs/` содержит только разрешённые файлы статического сайта и предназначена для GitHub Pages из ветки `master`. `.env` и другие секреты туда не копируются.
